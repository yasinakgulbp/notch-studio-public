Notch Studio: permission and foreground-service demonstrations

BP96 STUDIO · Android · 1.1.4. These are silent recordings of a dedicated emulator with synthetic app content. No private user messages, audio recordings, signing keys or app source code are included. The app is not an accessibility tool: its optional AccessibilityService API only hosts the island display, without reading screen content or performing actions.

1. Optional accessibility display: disclosure, skip and Android consent

2. Audio permission and user-initiated recording

3. Screen recording: cancel, fresh Android consent, active display and stop

4. Audio recording: start, ongoing island indicator and stop

The island stays visible while enabled through a specialUse foreground service and an ongoing notification. Recording uses microphone or mediaProjection foreground service types as appropriate. All recording files remain local unless the user explicitly shares a file.
